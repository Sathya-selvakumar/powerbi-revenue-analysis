# 📊 **Revenue Growth Analytics Dashboard (Power BI Project)**

---

## 🚀 **Project Overview**

This project focuses on building a **comprehensive Revenue Growth Analytics Dashboard** using Power BI to analyze business performance, identify trends, and support **data-driven decision-making**.

The dashboard provides insights into:

* 📈 Revenue growth patterns
* 💰 Sales performance
* 👥 Customer behavior
* 📦 Product-level analysis
* 🌍 Regional trends

This project simulates **real-world business intelligence reporting** used in organizations.

---

## 🎯 **Objectives**

* Analyze overall **revenue trends over time**
* Identify **top-performing products and regions**
* Track sales performance using **KPIs**
* Understand **customer purchasing patterns**
* Build an **interactive & visually appealing dashboard**

---

## 📁 **Dataset Description**

The dataset includes the following key fields:

* 🆔 Order ID
* 📅 Order Date
* 👤 Customer Name / ID
* 📦 Product Category
* 🏷️ Product Name
* 🔢 Quantity Sold
* 💵 Sales Amount
* 📊 Profit
* 🌍 Region / Location

---

## 🛠️ **Tools & Technologies Used**

* 📊 Power BI (Visualization & Dashboard Creation)
* 🔄 Power Query (Data Cleaning & Transformation)
* 🧠 DAX (Data Analysis Expressions)
* 📑 Excel / CSV Dataset

---

## 🔄 **Data Preprocessing**

Before building the dashboard, the data was cleaned and transformed:

* ✔️ Removed null & duplicate values
* ✔️ Converted data types (Date, Numeric, Text)
* ✔️ Created calculated columns
* ✔️ Built relationships between tables
* ✔️ Structured data for better performance

---

## 📐 **Data Modeling**

* ⭐ Used **Star Schema** for efficient analysis
* 📊 Fact Table → Sales Data
* 📂 Dimension Tables → Product, Customer, Region, Date
